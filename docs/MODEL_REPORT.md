# Аналіз моделі KSU_upgraded_v6.glb

Файл: 40,3 МБ, glTF 2.0, експортер Blender I/O 5.3. Розширення: `KHR_materials_emissive_strength`, `KHR_materials_specular` (обидва підтримує Three.js). Камер, світла й анімацій немає.

## Сумісність із Three.js
Завантажується без помилок і попереджень. Матеріали, текстури й альфа-маски відображаються правильно (перевірено на п'яти оглядах). Усі індекси 16-бітні, у кожного примітива є нормалі.
